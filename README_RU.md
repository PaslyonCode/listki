# Листки — портативные записки

Портативное приложение для Windows 10/11 x64. Установщик, .NET, Python и интернет не нужны. Все данные хранятся локально рядом с `Listki.exe`.

## Быстрый старт

1. Распакуйте архив в обычную папку, например `Документы\Listki`.
2. Запустите `Listki.exe`.
3. Справа посередине появится лёгкая полупрозрачная кнопка. Её можно перетащить мышью.

Папка `Listki-data` создаётся автоматически. В ней находятся записки, блокноты, настройки и резервные копии. Для работы приложения папка должна быть доступна для записи.

## Язык интерфейса

Щёлкните правой кнопкой по плавающей кнопке или значку в трее и выберите **Язык → Русский** или **Language → English**. Выбор сохраняется в `Listki-data\language.ini`; формат записок и индекс `LISTKI01` при этом не меняются.

## Главное меню

После клика по плавающей кнопке появляются четыре действия:

- **Новая** — создать пустую записку.
- **Из буфера** — создать записку с текстом из буфера обмена.
- **Последние** — открыть до десяти последних записок.
- **Блокнот** — выбрать блокнот, посмотреть его записки, создать или переименовать блокнот.

Клик вне меню закрывает его. В углах экрана действия автоматически размещаются столбиком, не выходя за пределы рабочего стола.

## Записка

- Заголовок редактируется прямо в верхней шапке по клику.
- По умолчанию используется заголовок **«Новая записка»**. В английском интерфейсе он отображается как **“New note”**.
- **Enter** или **Tab** завершают ввод заголовка; **Esc** отменяет изменения, сделанные с начала редактирования.
- Если очистить заголовок, снова показывается значение по умолчанию.
- **F2** и пункт «Переименовать» переводят курсор в то же поле заголовка.
- Текст можно копировать, вставлять и редактировать обычными средствами RichEdit.
- Окно перемещается за верхнюю шапку, размер меняется за границы и углы.
- Булавка закрепляет записку поверх окон.
- Корзина справа от булавки удаляет записку после подтверждения. Копия RTF остаётся в `Listki-data\Deleted`.
- Цветная кнопка открывает пять цветов бумаги.
- Три точки или правая кнопка мыши открывают меню форматирования, цвета текста, блокнота, скрытия и удаления.
- При выделении текста появляется панель **B / I / U / размер**. Выделение сохраняется после нажатия кнопки панели.

Изменения текста и заголовка сохраняются автоматически. **Esc** в поле текста скрывает записку; в поле заголовка сначала отменяет редактирование заголовка.

## Блокноты и поиск

Окно списков содержит поиск по заголовку и началу текста. Для блокнота показывается количество записок. Правый клик по блокноту позволяет переименовать или удалить его; удаление блокнота переводит записки в «Без блокнота», но не удаляет их.

## Трей и автозапуск

Правый клик по значку в трее открывает то же меню. Из него можно:

- показать или скрыть записки;
- вернуть плавающую кнопку к правому краю;
- изменить прозрачность неактивных записок;
- включить автозапуск Windows для текущего пользователя;
- открыть папку данных;
- сменить язык;
- завершить приложение.

Автозапуск выключен по умолчанию. Завершайте приложение через пункт **Выход** в меню трея.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+C / Ctrl+X / Ctrl+V | Копировать / вырезать / вставить текст |
| Ctrl+A | Выделить всё |
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| Ctrl+B / Ctrl+I / Ctrl+U | Жирный / курсив / подчёркивание |
| Ctrl+S | Сохранить немедленно |
| F2 | Редактировать заголовок |
| Enter / Tab в заголовке | Завершить ввод |
| Esc в заголовке | Отменить изменение заголовка |
| Esc в тексте | Скрыть записку |

## Обновление и перенос

Завершите приложение через трей и замените только `Listki.exe`. Папку `Listki-data` оставьте на месте — записки, блокноты, оформление, язык и расположение окон сохранятся. При переносе в другую папку сначала отключите автозапуск, затем перенесите EXE вместе с `Listki-data` и включите автозапуск снова.

## Сборка из исходников

Нужен MinGW-w64 для x86-64.

```bash
cd source
bash build.sh
```

Результат: `source/build/Listki.exe`. На Windows можно запустить `source\build.bat`.

Проверки модели, геометрии интерфейса и языка выполняются обычным `g++`; интеграционный тест Windows компилируется MinGW-w64. Полноценный запуск Win32 GUI выполняйте на Windows 10/11.

## Формат данных и резервные копии

Индекс `Listki-data\index.dat` использует формат `LISTKI01`, совместимый с предыдущими версиями. Текст и оформление каждой записки хранятся в отдельном RTF, предыдущие версии — в `.bak`. Настройка языка хранится отдельно в `language.ini`.

Приложение работает локально и не отправляет данные в сеть.
